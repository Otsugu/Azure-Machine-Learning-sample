## 3. 「これは正常です」リスト（**慌てないでください**）

強化学習が初めての方が「異常だ」と誤解しやすい**正常な挙動**です。

| 現象 | なぜ正常か | 参照 |
|---|---|---|
| **PickAndPlace で成功率が 0 のまま** | 疎な報酬では成功経験が集まらない。**問題設定の難しさ** | [01 章](01_強化学習の基礎.md) 1.4 |
| 動画が数秒しかない | 成功時にエピソードが終了する仕様 | [04 章](04_RL環境を触って理解する.md) TS #11 |
| **GUI にスライダーが出ない** | **panda-gym がデバッグ パネルを意図的に無効化している** | [04 章](04_RL環境を触って理解する.md) 4.6.1 |
| **GUI でマウスで物体を掴めない** | 同上（`COV_ENABLE_MOUSE_PICKING` が 0） | [04 章](04_RL環境を触って理解する.md) 4.6.1 |
| **クラウドで GUI が開かない** | Azure ML のコンピューティングはヘッドレス。**設計どおり** | [04 章](04_RL環境を触って理解する.md) 4.6 |
| **`human` モードで `render()` が `None`** | **`rgb_array` のときだけ画像を返す仕様** | [04 章](04_RL環境を触って理解する.md) 4.6.1 |
| **`render_roll` が GUI に反映されない** | `place_visualizer()` に `roll` が渡されていない。**仕様** | [04 章](04_RL環境を触って理解する.md) 4.6.3 |
| **手動操作でもキューブを掴めない** | 1 ステップの移動は最大 5 cm。**課題自体が難しい** | [04 章](04_RL環境を触って理解する.md) 4.6.4 |
| **`distance_threshold` を `gym.make` で渡せない** | panda-gym が公開していない。**仕様** | [07 章](07_演習1_報酬関数の改善.md) 7.8.1 |
| 同じ設定でも結果がばらつく | 乱数の影響が大きい領域 | [01 章](01_強化学習の基礎.md) 1.8 |
| クラスターのノードが 0 | `min_instances=0` の設計どおり | [03 章](03_AzureML環境構築.md) 3.4 |
| ランダム方策の成功率が Reach では 0 でない | 手先を直接動かせるため | [04 章](04_RL環境を触って理解する.md) 4.4 |
| `rollout_success_rate` と `eval_success_rate` が違う | 前者は探索ノイズ込み、後者は決定的行動 | [05 章](05_ベースライン実験.md) 5.3 |
| 初回のイメージ ビルドに十数分かかる | パッケージのダウンロードとビルド | [03 章](03_AzureML環境構築.md) TS #16 |
