## 1. 模倣学習の用語

| 用語 | 説明 |
|---|---|
| **模倣学習**（Imitation Learning, IL） | 上手な人（専門家）のやり方を見せて、同じ振る舞いを学習させること。報酬関数を設計しなくてよいのが利点 |
| **専門家**（expert） | お手本を提供する側。人間でも、先に学習させたプログラムでもよい。本ハンズオンでは **PPO で学習させたプログラム**を専門家として使う |
| **デモンストレーション**（demonstration, デモ） | 専門家の実演記録。「この状況では、この操作をした」の並び |
| **軌跡**（trajectory） | 1 回の実演の全記録。開始から終了までの「状況と操作」の列 |
| **BC**（Behavior Cloning / 行動クローニング） | 最も単純な模倣学習。「状況 → 操作」を**教師あり学習**で当てにいく。実質は分類問題 |
| **DAgger**（Dataset Aggregation） | 学習中の方策で動かし、**訪れた状況について専門家に正解を聞き直して**データを増やす手法 |
| **GAIL** | 「専門家の記録か、学習中の記録か」を見分ける判別器を作り、見分けがつかなくなるように方策を訓練する手法 |
| **分布シフト**（distribution shift） | 学習に使ったデータと、実際に遭遇する状況がずれること。模倣学習では**自分の出力が次の入力を変える**ため必ず起きる |

## 2. 環境と評価の用語

| 用語 | 説明 |
|---|---|
| **環境**（environment） | 学習対象の世界。本ハンズオンでは「棒を倒さないよう台車を動かす」CartPole |
| **エピソード**（episode） | 環境の 1 回分の試行。開始から終了まで |
| **ステップ**（step） | エピソード内の 1 回の操作 |
| **ホライズン**（horizon） | エピソードの長さ |
| **固定ホライズン** | **エピソード長が必ず同じ**環境。`seals/CartPole-v0` は常に 500 ステップ |
| **可変ホライズン** | 失敗すると途中で終わる環境。`CartPole-v1` は 17 ステップで終わることもある。**GAIL / AIRL の評価には使えない** |
| **リターン**（return） | 1 エピソードで得た報酬の合計。本ハンズオンの成績はこれ |
| **正規化リターン** | 「ランダムなら 0、専門家なら 1」になるよう変換した成績。`(方策 - ランダム) / (専門家 - ランダム)` |
| **方策**（policy） | 「この状況ではこう動く」というルール。学習で作るもの本体 |
| **シード**（seed） | 乱数の初期値。**同じシードなら同じ結果**になる。1 つのシードの結果だけで比較してはいけない |
| **PPO** | 強化学習アルゴリズムの一つ。本ハンズオンでは**専門家を作るためだけ**に使う。中身を理解する必要はない |

## 3. 機械学習の一般用語

| 用語 | 説明 |
|---|---|
| **エポック**（epoch） | 手元のデータ全体を 1 回学習し切ること |
| **バッチ サイズ**（batch size） | 1 回の重み更新に使うデータ件数 |
| **勾配更新**（gradient update） | モデルの重みを 1 回書き換えること。**更新回数 ≒ 学習量** |
| **ハイパーパラメーター** | 学習の前に人が決める設定値（エポック数、バッチ サイズなど） |
| **過学習**（overfitting） | 手元のデータには合うが、新しいデータには合わない状態 |

## 4. Azure Machine Learning の用語

| 用語 | 説明 |
|---|---|
| **ワークスペース**（workspace） | Azure ML の作業単位。実験・モデル・データがここにまとまる |
| **コンピューティング クラスター** | 学習を実行する計算機の集まり。**使っていないときはノード数 0 にできる**（課金が止まる） |
| **環境**（Environment） | ジョブを動かす Python 環境の定義。本ハンズオンでは [src/conda.yaml](../src/conda.yaml) |
| **ジョブ**（job） | Azure ML に投げる 1 回の実行。学習スクリプトはジョブとして動く |
| **コマンド ジョブ**（Command Job） | 「このコマンドを実行して」と指定する最も基本的なジョブ |
| **Sweep ジョブ**（Sweep Job） | ハイパーパラメーターを何通りも試すジョブ |
| **主要メトリック**（primary metric） | Sweep が「良し悪し」を判断する指標。本ハンズオンでは `normalized_return` |
| **早期終了**（early termination） | 見込みの薄い試行を途中で打ち切る仕組み |
| **データ資産**（data asset） | Azure ML に登録した、バージョン付きのデータ |
| **MLflow** | 実験の記録を残す仕組み。Azure ML はこれを標準で使う |
