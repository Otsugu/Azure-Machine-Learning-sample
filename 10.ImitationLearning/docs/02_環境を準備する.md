> **この章の目的**
> 手元の PC に Python 環境を作り、**ロボットのシミュレーターが動くこと**と

---

## 2.1 なぜローカル環境が必要なのか

本ハンズオンは **「手元で試す → Azure ML に投げる」** の 2 段構えです。

| 段階 | 目的 |
|---|---|
| **ローカル** | コードの誤りをすぐ潰す。ジョブの起動待ちが無いので試行錯誤が速い |
| **Azure ML** | 複数条件の実験を並列で回し、**結果を 1 か所に記録する** |

Microsoft のドキュメントも、学習スクリプトから Azure 固有のコードを外すことを推奨しています。

> "it's recommended to remove any code specific to Azure Machine Learning from your model training scripts. **This separation allows for an easier transition between local and cloud and is considered best practice for mature MLOps.**"
>
> 出典（Microsoft 公式）: https://learn.microsoft.com/azure/machine-learning/migrate-to-v2-execution-hyperdrive?view=azureml-api-2

本ハンズオンの `src/` のスクリプトは、この方針に従って **`azureml.*` を一切使いません**。記録は MLflow に統一しています。

---

## 2.2 必要なもの

| 項目 | 内容 |
|---|---|
| **Azure サブスクリプション** | ワークスペースを作れる権限が必要です |
| **PC** | Windows / macOS / Linux。**GPU は不要**です（本ハンズオンは CPU のみで完結します） |
| **ディスク空き容量** | 数 GB（PyTorch と PyBullet を含むため） |
| **PowerShell 7 以降**（Windows の場合） | `winget install --exact --id Microsoft.PowerShell` |

### ⚠ コストについて

本ハンズオンは **CPU のみ・短時間のジョブ**で構成しています。ただし、

> **Azure のコンピューティング リソースは、起動している間ずっと課金されます。**
> - コンピューティング クラスターは **`min_instances=0`** で作成します。ジョブが無い間はノード数が 0 になり、コンピューティングの課金が止まります。
> - **ただしストレージなど、ワークスペース付属リソースの課金は続きます。**
> - **終わったら [09 章](09_評価・コスト・後片付け.md) の後片付けを必ず実施してください。**
>
> 出典（Microsoft 公式）: https://learn.microsoft.com/azure/machine-learning/how-to-manage-optimize-cost?view=azureml-api-2

## 2.3 ⚠ なぜ conda を使うのか（pip だけでは入らないものがある）

本ハンズオンは物理シミュレーター **PyBullet** を使います。
この `pybullet` は、**PyPI に Windows 向けと macOS 向けのビルド済みホイールを公開していません。**

そのため Windows で `pip install panda-gym` を実行すると **ソースからのビルド**に入り、
C++ コンパイラーが無い環境では次のエラーで失敗します。

```text
error: Microsoft Visual C++ 14.0 or greater is required. Get it with "Microsoft C++ Build Tools":
https://visualstudio.microsoft.com/visual-cpp-build-tools/
```

一方 **conda-forge は `win-64` 向けのビルド済み `pybullet` を配布しています。**
そこで **`pybullet` だけを conda-forge から入れ、残りを pip で入れます。**

> 出典（参考情報・サードパーティ）
> - PyPI の `pybullet` 配布ファイル一覧: https://pypi.org/project/pybullet/#files
> - conda-forge の `pybullet` 配布パッケージ一覧: https://anaconda.org/conda-forge/pybullet
> - Microsoft C++ Build Tools: https://visualstudio.microsoft.com/visual-cpp-build-tools/

**この 1 点のためだけに conda を使います。** [setup/environment-local.yml](../setup/environment-local.yml) が対応済みです。

## 2.4 ローカル環境を作る

### ⚠ 先に確認: OS ごとの検証状況

| OS | 状況 |
|---|---|
| **Windows** | ✅ **検証済み**（本ハンズオンの構築に使用） |
| **macOS** | ⚠ **未検証**（スクリプトは用意していますが、実行確認はしていません） |
| **Linux** | ⚠ **未検証**（同上） |

### 2.4.1 Windows

```powershell
cd 10.ImitationLearning\setup
pwsh -NoProfile -File .\setup.ps1
```

### 2.4.2 macOS / Linux

```bash
cd 10.ImitationLearning/setup
bash setup.sh
```

### 2.4.3 手動で作る場合

```bash
cd 10.ImitationLearning/setup
conda env create --file environment-local.yml
conda run -n il-panda python verify_env.py
```

### スクリプトが行うこと

1. **Miniforge (conda) の導入** … 未導入の場合のみ
2. **conda 環境 `il-panda` の作成**（Python 3.10）
3. **Jupyter カーネル「Python (il-panda)」の登録**
4. **Azure CLI と `ml` 拡張の導入** … 未導入の場合のみ
5. **`verify_env.py` による動作確認**

> **何度実行しても同じ結果になります。** 途中で失敗したら、そのまま再実行してください。

> ⚠ **9 章（強化学習）とは別の環境になります。**
> `imitation` 1.0.1 が `stable-baselines3~=2.2.1` を要求するのに対し、9 章は 2.4.1 を使うためです。
> 出典: https://pypi.org/pypi/imitation/json ／ https://peps.python.org/pep-0440/#compatible-release

> ⚠ **無言のまま進まない場合**: 別のターミナルで conda を実行していると、
> conda はロックを待って停止します。[A1 の 1-2](A1_トラブルシューティング.md) を参照してください。

```text
  matplotlib           3.10.9

  azureml-mlflow       1.60.0
  ipykernel            7.3.0

[3/4] ピックアンドプレース環境の動作確認（エピソード長が固定であること）
  env_id            : il/PandaPickAndPlace-v0
  observation_space : Box(-10.0, 10.0, (25,), float32)
  action_space      : Box(-1.0, 1.0, (4,), float32)

  expert successes  : [True, True, True]

[4/4] Azure ML SDK と MLflow の import 確認
  mlflow tracking uri : sqlite:///.../mlflow.db
  ※ ローカル実行では、この追跡 URI をワークスペースのものに差し替える必要があります

OK: ローカル環境の検証に成功しました。
```

> **参考値です（2026-08-18 / Windows 10 で実測）。** バージョンは環境により異なることがあります。

### ⚠ ここで注目してほしい点

| 出力 | 意味 |
|---|---|
| `episode lengths : [50, 50, 50]` | **エピソード長が固定**であることの確認。[01 章 1.5](01_模倣学習の基礎.md) の理由がここで効きます |
| `observation_space : Box(..., (25,), ...)` | 観測は **25 個の数値が並んだ 1 本のベクトル**です（[01 章 1.5](01_模倣学習の基礎.md)） |
| `action_space : Box(-1.0, 1.0, (4,), ...)` | 行動は **4 つの連続値**（手先を x / y / z に動かす量と、指の開閉） |
| `numpy 1.26.4` | **`panda-gym` が `numpy<2` を要求する**ため 1 系です（出典: https://github.com/qgallouedec/panda-gym/blob/master/setup.py ） |
| `mlflow tracking uri : sqlite:///...` | ローカルでは MLflow が**カレント フォルダーに記録を作ります**。Azure ML に向ける方法は [03 章](03_AzureML環境構築.md) で扱います |

## 2.7 ⚠ うまくいかないときは

| 症状 | 参照先 |
|---|---|
| `conda` が見つからない | [A1 の 1-1](A1_トラブルシューティング.md) |
| conda が無言のまま止まる | [A1 の 1-2](A1_トラブルシューティング.md) |
| `error: Microsoft Visual C++ 14.0 or greater is required.` | [A1 の 1-3](A1_トラブルシューティング.md) |
| `verify_env.py` がパッケージ未導入で失敗する | [A1 の 1-4](A1_トラブルシューティング.md) |
| VS Code のエディター上だけ `import` がエラーになる | **選択中の Python インタープリターが `il-panda` になっていません。** コマンド パレットで `Python: Select Interpreter` を実行して切り替えてください<br>出典: [Using Python environments in VS Code](https://code.visualstudio.com/docs/python/environments#_working-with-python-interpreters) |
| ノートブックのセルが別の環境で動く | **カーネルが `il-panda` になっていません。** ノートブック右上のカーネル選択から「Python (il-panda)」を選んでください（2.4 の「スクリプトが行うこと」の 3.） |

## この章のまとめ

- ローカルと Azure ML の **2 段構え**で進める
- **`pybullet` は conda-forge から入れる**（PyPI に Windows / macOS 向けホイールが無い）
- conda 環境 `il-panda`（Python 3.10）を作る。**9 章とは別環境**
- **`verify_env.py` が `OK:` を出したら次へ**
- **macOS / Linux は未検証**。失敗したら手動作成に切り替える
